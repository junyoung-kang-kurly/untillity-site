화면 구석에 5초 머물다 사라지는 알림으로는 중요한 회의를 챙기기 어렵습니다.

메신저와 이메일 알림이 쏟아지는 자리에 회의 알림도 똑같은 모양으로 뜹니다. 코딩이나 문서 작업에 몰입해 있으면 알아채기 힘들고, 알아챘더라도 잠시 한눈판 사이에 사라져 버립니다.

방금 화면 오른쪽 위에 지나간 배너처럼, 쏟아지는 일상 알림 사이에 묻히면 회의를 깜빡하기 쉽습니다.

언틸리티는 회의 시간을 확실하게 인지할 수 있도록 전혀 다른 방식을 택했습니다.

실제 구동 화면

어떤 화면 위에 있든 확실하게 덮어줍니다

웹 브라우저 데모를 넘어, 실제 macOS 환경에서 어떻게 동작하는지 녹화한 화면입니다.

알림이 울리면 연결된 모든 모니터에 전체 화면 창이 동시에 뜹니다. 다른 앱이 네이티브 전체 화면 모드로 실행 중이거나 다른 가상 데스크탑(Space)에 있더라도 가려지지 않고 그 위에 즉시 표시됩니다.

계정을 앱에 따로 연결할 필요가 없습니다. macOS가 이미 동기화하고 있는 일정을 그대로 활용합니다.

Google이나 Microsoft 계정 정보를 앱에 직접 입력하지 않습니다. 비밀번호를 묻지도 않고, 로그인 토큰을 앱 내에 저장하지도 않습니다.

캘린더 관리

알림받을 캘린더만 쏙 골라내기

업무 회의만 받고 싶다면, 개인 일정이나 공휴일 알림은 손쉽게 꺼둘 수 있습니다.

계정별로 캘린더가 깔끔하게 분류되어 표시됩니다. 회사 업무, 팀 캘린더, 개인 일정 중 알림을 원치 않는 항목만 체크를 해제하세요.

새로 추가된 캘린더는 자동으로 알림이 켜집니다. 끈 캘린더만 기억하는 방식이라, 회사에서 새 프로젝트 캘린더가 추가되었을 때 기본이 '꺼짐'이라 회의를 놓치는 일이 없습니다.

FAQ

왜 설치할 때 경고가 뜨나요? 위험한 앱인가요?

Apple 공식 개발자 프로그램(연 $99)에 등록하지 않고 개인이 무료 배포하는 오픈소스 앱이기 때문에 표시되는 정상적인 보안 경고입니다. 악성 코드가 없는 안전한 앱이니 안심하셔도 좋습니다.

설치 시 한 가지만 주의해 주세요: 경고 창에서 엔터 키를 누르면 파란색 기본 버튼인 「휴지통으로 이동」이 실행됩니다. 반드시 「완료」를 누른 뒤 시스템 설정에서 「그래도 열기」를 진행해 주세요.

최초 1회만 승인하면 다음부터는 묻지 않으며, 앱을 업데이트해도 권한 설정이 유지됩니다.

제 캘린더 내용이 외부로 유출되지는 않나요?
전혀 유출되지 않습니다. 언틸리티는 인터넷 연결을 전혀 사용하지 않는 순수 오프라인 앱입니다. 사용자 분석 트래커, 오류 수집, 자동 업데이트 체크 등 어떤 통신도 하지 않습니다. 터미널에서 lsof -i와 nettop 명령으로 활성 네트워크 연결이 0개임을 직접 확인하실 수 있습니다. 동작 로그 또한 사용자 맥 내부(~/Library/Logs/Untillity/untillity.log)에만 저장됩니다.
어떤 권한을 요구하나요?
캘린더 전체 접근(읽기) 권한 하나만 사용합니다. 일정 조회만 수행하며, 일정을 추가하거나 수정, 삭제하지 않습니다. 손쉬운 사용(접근성) 권한이나 화면 기록 권한은 일절 요구하지 않습니다.
어떤 캘린더를 지원하나요? 구글 로그인이 필요한가요?
앱에 직접 계정을 로그인할 필요가 없습니다. macOS의 시스템 설정 → 인터넷 계정에 등록된 캘린더(Google, Outlook/Exchange, iCloud, CalDAV 등)를 그대로 읽어오므로, 맥 기본 캘린더에 연동된 모든 일정을 그대로 지원합니다.
알림이 하나도 안 떠요.
메뉴 막대 아이콘 클릭 후 [디버그] 로그 폴더 열기에서 로그를 확인해 보세요. 캘린더 읽기 권한이 정상 부여되었는지 확인할 수 있으며, 회의가 있는데도 알림이 뜨지 않았다면 해당 일정이 제외 규칙(종일 일정, 이미 거절한 회의, 장시간 일정 등)에 해당하여 제외된 사유가 명확히 기록되어 있습니다.
메뉴 막대에 아이콘이 안 보여요.
응용 프로그램 폴더에서 언틸리티를 한 번 더 실행해 보세요. 이미 실행 중이더라도 설정 창이 바로 열립니다. 메뉴 막대 아이콘 숨김 유틸리티(Hidden Bar, Bartender 등)를 사용 중이라면 숨김 영역을 펼쳐 확인해 주세요. 아이콘이 필요 없다면 설정 창에서 메뉴 막대 아이콘을 끌 수도 있습니다.
배터리 소모나 발열은 없나요?
평소 CPU 점유율은 0.0%이며, 메모리 사용량도 약 47MB 내외로 매우 가볍습니다. 알림 시각의 정확도를 지키면서도 맥의 정상적인 유휴 절전(잠자기)을 방해하지 않으므로 배터리 부담 없이 사용하실 수 있습니다.
대기 화면은 화면 잠금 기능인가요?
아닙니다. 잠시 자리를 비울 때 화면을 덮어두고, 돌아왔을 때 다음 회의 일정을 바로 확인하기 위한 편의 화면입니다. 마우스 클릭이나 Esc 키로 즉시 닫힙니다. 화면을 안전하게 잠그려면 macOS 기본 잠금 단축키(⌃⌘Q)를 사용해 주세요.

중요한 회의, 이제 놓치지 마세요.
