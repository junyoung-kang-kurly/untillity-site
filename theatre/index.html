왜 설치할 때 경고가 뜨나요? 위험한 앱인가요?
Apple 공증(notarization)을 받지 않아서입니다. 개발자 프로그램(연 $99)에 가입하지 않고 만들었기 때문이고, 아는 사람에게만 나눠주는 앱이라 가입하지 않았습니다. 대신 서명은 확실히 합니다 — 고정된 self-signed 인증서로 서명해서, 업데이트해도 캘린더 권한을 다시 주지 않아도 됩니다. 조심할 것은 하나입니다: 경고 창의 기본 버튼이 「휴지통으로 이동」이라, 안내 없이 Return 을 누르면 앱이 삭제됩니다. 설치 안내를 보면서 하세요. 한 번만 통과하면 이후 업데이트에서는 다시 묻지 않습니다.
제 캘린더 내용이 어디로 가나요?
아무 데도 가지 않습니다. 이 앱은 네트워크를 아예 쓰지 않습니다 — 분석도, 크래시 리포팅도, 업데이트 체크도 없습니다. 선언이 아니라 측정으로 담보합니다: 앱을 띄워 두고 lsof -i -p <pid> 와 nettop -p <pid> 를 돌려 연결이 0인 것을 직접 확인할 수 있습니다(개발 중 실측에서도 두 명령 모두 행 0개였습니다). 로그는 ~/Library/Logs/Untillity/untillity.log, 사용자 홈 안에만 남습니다.
어떤 권한을 요구하나요?
캘린더 전체 접근 하나입니다. 읽기 전용으로 쓰고, 일정을 만들거나 고치거나 지우지 않습니다. 손쉬운 사용(접근성) 권한과 화면 기록 권한은 요구하지 않습니다 — 전체 화면 알림은 비활성화 패널로, 전역 단축키는 Carbon RegisterEventHotKey 로 만들어서 둘 다 접근성 권한 없이 동작합니다.
어떤 캘린더를 지원하나요? 구글 로그인이 필요한가요?
앱이 직접 구글이나 마이크로소프트에 로그인하지 않습니다. macOS 캘린더에 연결된 계정을 읽습니다. 그래서 시스템 설정 → 일반 → 인터넷 계정에서 계정을 한 번 연결해 두면 구글이든 Exchange든 iCloud든 CalDAV든 전부 같은 경로로 읽힙니다. 캘린더는 계정별로 묶여 보이고, 보기 싫은 것만 끄면 됩니다.
알림이 하나도 안 떠요.
먼저 로그를 보세요 — 메뉴 막대 → [디버그] 로그 폴더 열기. [권한] 읽기 가능 → 이벤트 캘린더 N개 줄의 N이 0이면 캘린더를 못 읽고 있는 것이고, 회의가 있는데 안 떴다면 [판정] 줄에 제외 사유가 조건 번호와 함께 적혀 있습니다(예: F2-7 장시간 일정). 참고로 0.2.7 이전 버전에는 첫 설치 직후 그 세션에서 캘린더가 비어 보이는 결함이 있었고, 지금은 권한을 받은 즉시 캘린더를 다시 읽도록 고쳐져 있습니다.
메뉴 막대에 아이콘이 안 보여요.
앱을 한 번 더 실행하세요 — 응용 프로그램 폴더에서든 Spotlight에서든, 이미 켜져 있어도 설정 창이 열립니다. 아이콘을 숨기는 도구를 쓰고 있으면 메뉴 막대의 ‹ 를 눌러 숨은 영역을 펼쳐 보세요. 아이콘이 거슬리면 설정에서 끌 수도 있습니다 — 꺼도 알림은 그대로 뜹니다.
알림 때문에 맥이 계속 깨어 있지는 않나요? 배터리는요?
맥이 자는 것을 막지 않습니다. 알림 시각을 정확히 맞추려고 App Nap만 억제하고 유휴 절전은 건드리지 않습니다 — 실제로 절전을 막는 옵션을 썼던 적이 있어 바로잡았습니다. 확인 방법은 pmset -g assertions | grep -i untillity 이고, 아무것도 안 나오는 것이 정상입니다. 평소 CPU는 거의 0이고 메모리는 47MB 안팎입니다(같은 시점 실측 46.8MB).
대기 화면은 화면 잠금인가요?
아닙니다. 아무나 Esc 를 누르거나 클릭하면 닫힙니다. 자리를 비울 때 화면을 덮고 돌아왔을 때 다음 회의를 바로 보려는 화면이지, 잠그는 화면이 아닙니다. 진짜 잠금은 macOS 의 ⌃⌘Q 입니다.
지우려면 어떻게 하나요?
설정에서 「로그인할 때 언틸리티 시작」을 끄고, 응용 프로그램 폴더의 Untillity.app 을 휴지통으로 옮기면 됩니다. 캘린더 권한까지 지우려면 tccutil reset Calendar com.bonjugi.untillity (sudo 필요 없습니다), 로그는 ~/Library/Logs/Untillity/ 를 지우면 됩니다. 앱이 남긴 것은 그 둘과 설정값뿐입니다.

닫기 전에는 안 사라집니다.
